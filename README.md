# Trilha de Revisão · Direito Administrativo

Revisão passo a passo, com questões comentadas, das aulas do **Prof. Pietro Medeiros**:

- **Responsabilidade Civil do Estado** (9 etapas)
- **Serviços Públicos** (8 etapas)

**Acesse:** https://advpietromedeiros-sudo.github.io/revisao-adm-pietro/

## Como funciona

1. **Relembre**: cada etapa abre com uma revisão relâmpago dos pontos-chave.
2. **Fixe**: questões de Certo/Errado e de completar lacunas.
3. **Aplique**: múltipla escolha e associação de colunas.
4. **Integre**: um caso prático com resposta-modelo e checklist.

Acerte 70% para liberar a etapa seguinte; ao concluir a trilha, abre o **Desafio final**. O **Caderno de erros** guarda
o que você errou até acertar. O progresso fica salvo só no seu navegador.
